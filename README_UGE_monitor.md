# UGE Notification Monitor — инструкция по установке и восстановлению

Эта инструкция описывает рабочую схему проверки уведомлений UGE на macOS.

## Что делает система

Сценарий работает так:

1. Открывает страницу UGE:
   `https://expinterweb.inclusion.gob.es/iley11/inicio/showTramites.action?proc=1&procedimientoSel=200`
2. Нажимает `Ver Notificaciones`.
3. Нажимает `Autenticarse`.
4. Открывает AutoFirma.
5. Выбирает сертификат `YOUR AUTOFIRMA`.
6. Нажимает `Aceptar`.
7. Проверяет страницу уведомлений.
8. Отправляет результат в Telegram.
9. Отдельные уведомления автоматически НЕ открывает.

Telegram может присылать:

- `✅ UGE: уведомлений нет.`
- `🔴 UGE: возможно есть уведомление или изменилось состояние страницы.`
- `⚠️ UGE monitor: проверка завершилась ошибкой.`

---

# 1. Что нужно установить

На Mac должны быть установлены:

- Google Chrome
- AutoFirma
- Node.js / npm
- Terminal
- рабочий сертификат для UGE
- Telegram bot

Проверить Node:

```bash
node -v
npm -v
```

---

# 2. AutoFirma

AutoFirma должна работать вручную до настройки автоматизации.

Проверка вручную:

1. Открыть UGE.
2. Нажать `Ver Notificaciones`.
3. Нажать `Autenticarse`.
4. В Chrome подтвердить открытие AutoFirma.
5. Выбрать нужный сертификат.
6. Нажать `Aceptar`.
7. Убедиться, что открывается страница уведомлений.

## Если AutoFirma не соединяется с UGE

Если появляется ошибка связи с AutoFirma:

1. Открыть AutoFirma отдельно.
2. В верхнем меню выбрать:

   `Herramientas → Restaurar instalación`

3. Дождаться сообщений:

```text
INFO: Inicio de la restauración
INFO: Certificado de CA importado.
INFO: Certificado SSL importado.
INFO: Fin de la restauración
```

4. Закрыть AutoFirma.
5. Закрыть Chrome.
6. Закрыть Terminal.
7. Перезагрузить Mac.
8. Повторить ручную проверку UGE.

---

# 3. Разрешения macOS

Для автоматического выбора сертификата Terminal должен иметь доступ к интерфейсу macOS.

Открыть:

`Системные настройки → Конфиденциальность и безопасность → Универсальный доступ`

Включить:

```text
Terminal = ВКЛ
```

Также проверить:

`Системные настройки → Конфиденциальность и безопасность → Автоматизация`

Если есть Terminal:

```text
Terminal → System Events = ВКЛ
```

После изменения разрешений полностью закрыть Terminal через `⌘Q` и открыть заново.

---

# 4. Настройки питания Mac

Чтобы автоматическая проверка работала:

- Mac должен быть включён.
- Mac желательно держать на зарядке.
- Пользователь должен быть залогинен.
- Экран не должен быть заблокирован.
- Крышку лучше держать открытой.
- Сам дисплей можно выключать, если система не блокирует пользовательскую сессию.

Рекомендуемая настройка:

`Системные настройки → Аккумулятор → Параметры`

Включить:

```text
Не переходить в режим сна автоматически,
когда дисплей выключен при работе от сети питания
```

# 5. Telegram Bot

Создать бота через BotFather.

Нужны:

```text
TELEGRAM_BOT_TOKEN="YOUR_TOKEN_HERE"
TELEGRAM_CHAT_ID="YOUR_CHAT_ID_HERE"
```

Никогда не публиковать реальный Telegram token в GitHub.

Если token случайно попал в публичный репозиторий или скриншот — лучше перевыпустить его через BotFather.

# 8. Ручная проверка

Перед включением расписания обязательно проверить вручную:

```bash
cd ~/Downloads/uge-final-telegram
npm run check
```

При нормальной работе в Terminal должно появиться примерно:

```text
1. Открываю UGE...
2. Открываю Ver Notificaciones...
3. Нажимаю Autenticarse...
Жду окно выбора сертификата...
✅ Выбран YOUR AUTOFIRMA и нажат OK.
Жду Aceptar...
4. Проверяю результат...
✅ UGE: уведомлений нет.
📨 Telegram отправлен.
```

В Telegram должно прийти сообщение.

---

# 9. Автоматический запуск раз в час

Автоматическая проверка настроена через macOS `launchd`.

Запуск идёт через Terminal, потому что именно Terminal имеет разрешение `Универсальный доступ` и может управлять системным окном выбора сертификата.

Файл запуска:

```text
run-uge.command
```

Задача launchd:

```text
com.zlata.uge.telegram
```

Проверка регистрации задачи:

```bash
launchctl print gui/$(id -u)/com.zlata.uge.telegram
```

Если задача существует, появится большой блок параметров.

---

# 10. Проверить автоматический запуск сразу

Не нужно ждать час.

Выполнить:

```bash
launchctl kickstart -k gui/$(id -u)/com.zlata.uge.telegram
```

После этого должно:

1. Открыться окно Terminal.
2. Запуститься проверка UGE.
3. Выбраться сертификат YOUR AUTOFIRMA (нужный сертификат).
4. Нажаться `Aceptar`.
5. Прийти Telegram.

Если Telegram пришёл после этой команды — автоматическая схема работает.

---

# 11. Что происходит после перезагрузки Mac

После перезагрузки:

1. Нужно войти в пользовательский аккаунт.
2. LaunchAgent загрузится снова.
3. Благодаря `RunAtLoad` проверка должна запуститься после входа.
4. Затем продолжит выполняться примерно раз в час.

Пока Mac выключен, проверки не выполняются.

Пропущенные проверки задним числом не догоняются.

---

# 12. Если перестало работать

Сначала проверить вручную:

```bash
cd ~/Downloads/uge-final-telegram
npm run check
```

Если вручную работает, а автоматически нет — проверить launchd:

```bash
launchctl print gui/$(id -u)/com.zlata.uge.telegram
```

И сделать тест:

```bash
launchctl kickstart -k gui/$(id -u)/com.zlata.uge.telegram
```

Если не выбирается сертификат:

- проверить `Terminal = ВКЛ` в `Универсальном доступе`;
- проверить `Terminal → System Events = ВКЛ` в `Автоматизации`;
- полностью закрыть Terminal через `⌘Q`;
- открыть Terminal снова.

Если AutoFirma показывает ошибку связи:

```text
AutoFirma → Herramientas → Restaurar instalación
```

# 13. Безопасность

Никогда не загружать в GitHub:

```text
.env
*.p12
*.pfx
chrome-profile/
node_modules/
logs/
```

Рекомендуемый `.gitignore`:

```gitignore
.env
*.p12
*.pfx
chrome-profile/
node_modules/
logs/
.DS_Store
```

Также не публиковать:

- Telegram Bot Token
- пароль сертификата
- приватный ключ
- `.p12` / `.pfx`
- сохранённый Chrome profile

---

# 14. Что можно безопасно хранить на GitHub

Можно хранить:

- этот `README.md`;
- обезличенный код без токенов и сертификатов;
- `.env.example`;
- `package.json`;
- шаблон launchd;
- инструкции восстановления.

Лучше использовать **Private Repository**, даже если секретов внутри нет.

---

# 15. Важное ограничение

Текущая схема зависит от macOS GUI:

```text
Chrome → AutoFirma → системное окно сертификата
```

Поэтому обычный Linux VPS не является прямой заменой.

Чтобы полностью отвязаться от личного MacBook, нужен:

- отдельный постоянно включённый Mac mini;
- либо удалённый Mac;
- либо полностью другая серверная реализация авторизации.

---

## Итоговая рабочая схема

```text
launchd
   ↓
Terminal
   ↓
Chrome
   ↓
UGE
   ↓
AutoFirma
   ↓
NAME OF SIGN HOLDER
   ↓
Aceptar
   ↓
Проверка уведомлений
   ↓
Telegram
```

Отдельные уведомления автоматически не открываются.
